Meta Prompting

Fase 1 · Lección extra 1.6.2 · ~13 min · Prompt Engineering

Few-shot prompting ancla el modelo con ejemplos concretos de contenido. Meta prompting hace lo contrario: en vez de darle contenido, le da la forma — la estructura, la sintaxis y el patrón de razonamiento que debe seguir, independientemente del tema concreto.

Few-shotMeta prompting
Qué se anclaContenido (ejemplos reales)Estructura y formato del razonamiento
Dependencia del dominioAlta — los ejemplos son específicos del casoBaja — la plantilla es reutilizable entre dominios
Coste de tokensCrece con cada ejemplo añadidoConstante, independiente del tema
Plantilla meta (sin contenido específico) Resuelve el siguiente problema usando esta estructura:
1. Identifica las variables conocidas.
2. Identifica qué se pide.
3. Elige la fórmula o método aplicable.
4. Aplica el método paso a paso.
5. Verifica que el resultado responde exactamente a lo que se pedía.

Problema: [se inserta aquí cualquier problema, sin que la plantilla cambie]
Por qué es útil La misma plantilla meta sirve para un problema de física, uno de programación o uno de planificación de proyecto — solo cambia el contenido que se inserta. Esto la hace ideal para sistemas que generan prompts dinámicamente para tareas variadas.

Meta prompting para generar prompts

Una variante habitual: pedirle al propio modelo que actúe como "ingeniero de prompts" y te ayude a diseñar o mejorar la estructura de un prompt, en lugar de resolver la tarea directamente.

Meta prompting como diseño de prompts Eres un experto en prompt engineering. No resuelvas la tarea. En su lugar, propón la estructura óptima de un prompt (secciones, orden, restricciones de formato) para que un LLM genere informes de incidencias técnicas a partir de logs de error sin procesar.
