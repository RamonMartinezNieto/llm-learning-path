# LLM Learning Path

Un camino de aprendizaje autodirigido desde usuario casual de IA hasta ingeniero de LLMs en producción. 60 lecciones HTML interactivas (55 lecciones numeradas + 5 sub-lecciones de técnicas de prompting) estructuradas en 9 fases: ingeniería de prompts, uso avanzado en chat, integración con IDEs y DevOps, construcción de APIs, código agéntico y sistemas de IA en producción.

Ver `plan-aprendizaje-ia.md` para el temario detallado lección por lección.

## 📚 Contenido del Curso

Este curso está estructurado en 9 fases progresivas:

- **Fase 0 - Fundamentos Conceptuales**: Cómo funcionan los LLMs, tokens, contexto, temperatura, embeddings, el ecosistema de modelos y proveedores, limitaciones y alucinaciones
- **Fase 1 - Prompt Engineering**: Anatomía de un buen prompt, técnicas básicas y avanzadas (chain-of-thought, self-consistency, tree-of-thought, prompt chaining, meta-prompting...), prompts para código vs. texto, gestión de contexto, evaluación y refinamiento iterativo
- **Fase 2 - Chat Mode Avanzado**: La IA como motor de investigación y síntesis, análisis de documentos, aprendizaje acelerado, escritura técnica, toma de decisiones y comparativa de modelos
- **Fase 3 - IA Integrada en el Entorno de Desarrollo**: Autocompletado, refactorización y code review, generación de tests, debugging, documentación automática, herramientas como Cursor, Copilot y Claude Code
- **Fase 4 - IA en el Ciclo DevOps y Flujo de Trabajo**: Revisión de Pull Requests, pipelines CI/CD, seguridad y detección de vulnerabilidades, documentación técnica de proyectos, terminales y CLI, gestión de proyectos
- **Fase 5 - Construcción con APIs de IA**: Primeros pasos con la API, prompt caching, tool use y function calling, structured outputs, streaming, gestión de conversaciones y memoria, RAG, embeddings y búsqueda semántica
- **Fase 6 - Código Agéntico (Agentic AI)**: Arquitectura ReAct, diseño de herramientas para agentes, bucles de agente, agentes de código, multi-agent systems, evaluación y trazabilidad, frameworks como LangChain, AutoGen, CrewAI y Claude Agent SDK
- **Fase 7 - Sistemas de IA en Producción**: Fine-tuning vs. prompting, evaluación sistemática de modelos, observabilidad y logging, seguridad (prompt injection, jailbreaking), escalado y optimización de costes, patrones de arquitectura
- **Fase 8 - IA Aplicada a Otras Áreas**: Investigación y análisis de mercado, automatización de flujos de negocio, contenido multimodal, productividad personal, análisis de datos, automatización con Zapier/Make/n8n
