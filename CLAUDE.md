# LLM Learning Path

Curso autodirigido en español que enseña a usar la IA (LLMs) de forma progresiva: desde usuario casual hasta ingeniero de sistemas de IA en producción. Son variass lecciones HTML interactivas organizadas en fases, cubriendo prompt engineering, integración con IDEs (Cursor, Copilot, Claude Code), construcción con APIs (tool use, RAG, embeddings, streaming), agentes autónomos, sistemas multi-agente y despliegue/observabilidad en producción.

Ver `README.md` para el índice de fases y `plan-aprendizaje-ia.md` para el temario detallado lección por lección.
